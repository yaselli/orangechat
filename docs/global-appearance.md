# 全局材质、柔和暗色与设置背景

本次只扩展外观，不调整页面布局、分组、导航或业务功能。

- 原有整体主题材质通过共用组件覆盖通用卡片、列表项、圆角表面、菜单、弹窗和底部面板。调用点仅调整组件导入，继续委托原生 Material 3 控件处理布局、点击、禁用状态与无障碍语义。
- 品牌色、颜色选择器色块、错误及状态背景保留其颜色语义。矩形整页表面作为页面背景处理，不在整张壁纸上加磨砂。
- 菜单与弹窗使用独立的静态厚材质，不跨窗口采样背景；实时模糊仍只采样壁纸。纯色根背景不创建没有视觉收益的捕获图层。
- 设置 → 颜色模式新增「柔和暗色」：中性灰绿基底、浅色文字，图片仅在明确选用此模式时压暗。普通深色与 AMOLED 设置继续独立生效。浅色模式不恢复此前删除的壁纸遮罩。
- 设置 → 显示设置 → 插图素材的设置背景图，改为设置主页及所有配置子页面共用。沿用已有 settingsBackgroundPath 字段，无需重新导入旧图片。导航页面共用已加载的壁纸画笔，关闭壁纸淡入，并在导航动画下方保留目的页壁纸，避免返回时重新加载或露出纯色底。
- 设置卡片不透明度沿用 settingsUiAlpha，统一作用于设置范围内的材质；菜单和弹窗仍保持可读的不透明度。

检查覆盖旧材质参数、柔和暗色文字对比度、设置路由覆盖、图片跨页面及返回、清除图片、全局卡片材质差异、点击操作与弹窗背景隔离。PR 检查通过后自动生成包含已有日常聊天与修正的 Debug 测试包，保持原签名和版本号，不公开发布。

流式聊天的材质气泡仅将背景放入模糊缓冲层，正文直接绘制；不再对每次增量启动尺寸补间动画。壁纸重绘时显式同步模糊层。RenderingFlickerDeviceTest 在下一帧检查增长/缩短的正文边界、文字和玻璃填充，并逐帧检查设置返回过渡及壁纸画笔复用。
