# 全局材质、柔和暗色与设置背景

本次只扩展外观，不调整页面布局、分组、导航或业务功能。

- 原有整体主题材质通过共用组件覆盖通用卡片、列表项、圆角表面、菜单、弹窗和底部面板。调用点仅调整组件导入，继续委托原生 Material 3 控件处理布局、点击、禁用状态与无障碍语义。
- 品牌色、颜色选择器色块、错误及状态背景保留其颜色语义。矩形整页表面作为页面背景处理，不在整张壁纸上加磨砂。
- 菜单与弹窗使用独立的静态厚材质，不跨窗口采样背景；实时模糊仍只采样壁纸。纯色根背景不创建没有视觉收益的捕获图层。
- 设置 → 颜色模式新增「柔和暗色」：中性灰绿基底、浅色文字，图片仅在明确选用此模式时压暗。普通深色与 AMOLED 设置继续独立生效。浅色模式不恢复此前删除的壁纸遮罩。
- 设置 → 显示设置 → 插图素材的设置背景图，改为设置主页及所有配置子页面共用。沿用已有 settingsBackgroundPath 字段，无需重新导入旧图片。导航页面各自保留背景，以支持进入与返回动画。
- 设置卡片不透明度沿用 settingsUiAlpha，统一作用于设置范围内的材质；菜单和弹窗仍保持可读的不透明度。
