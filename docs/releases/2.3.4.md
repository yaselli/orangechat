本次更新加入一起听，并提供可选的工具按需加载。

- 新增网易云一起听：每位用户连接自己的服务、登录自己的账号；支持搜歌、点歌、待播队列、歌词和后台播放，AI 可通过工具选歌及控制播放。
- 优化一起听界面：唱片卡片、迷你播放器、推荐／待播／歌词页面，支持歌词定位与分享。
- 新增「听到喜欢的歌词时说一句」：按角色手动开启，默认关闭，无需打开普通主动消息开关；遵守免打扰时段，使用独立的精简请求。
- 新增「工具按需加载（实验）」：正式版与 Debug 均可按角色开启，默认关闭。常用工具保持完整说明，其余已启用的插件与 MCP 工具自动进入简短目录，需要时再加载；关闭开关可恢复全量发送。
- 保留约定的记忆、拍一拍、贴表情、一起听、联网、时间提醒、日常辅助、表情包及天气工具常驻；默认识别 OB 外置记忆库接口。按需加载继续使用原有权限和审批。
- Debug 的请求体积面板新增全量工具、实际发送工具及目录的对比；正式版继续隐藏调试面板。

一起听需要部署个人音乐服务，部署说明见 [服务文档](https://github.com/yaselli/watermelon-chat/blob/build/stable-release/services/shared-music/README.md)。QQ 音乐保留实验入口，登录与播放尚不稳定，目前建议使用网易云。

按需加载效果取决于模型发现和调用工具的能力；首次加载会增加模型往返，尚未完成真实模型的自然查找验收，不承诺固定的 token 节省比例。

正式版为 **2.3.4**，Debug 为 **2.3.4-debug.1**，版本代码均为 **169**。请按原渠道覆盖安装，无需卸载。已安装 2.3.3 兼容版且开启更新提醒的用户，可在发布后通过软件检查更新；仍停留在 2.3.2 或更早版本的用户，应手动下载安装对应渠道。
