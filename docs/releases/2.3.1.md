# 西瓜瓣 2.3.1

- 改善部分兼容接口的流式回复稳定性，避免空响应或空引用数据导致回复中断。
- 识别接口服务端已经执行的工具结果，避免手机再次执行同一工具。
- 改善工具调用事件的关联，兼容省略可选事件 ID 的接口。
- 优化聊天记录搜索索引，减少大量历史记录下更新和删除索引的开销。
- 搜索结果及时显示修改后的会话标题和更新时间。

正式版：`2.3.1`，版本代码 `166`。
Debug：`2.3.1-debug.1`，版本代码 `166`，功能修复与正式版相同，额外提供测试诊断。

手机通常选择 `arm64-v8a` 安装包；`x86_64` 用于对应架构设备／模拟器。
已经安装 `2.3.0` 的用户可在“设置 → 关于 → 检查更新”获取同渠道的新版本。
更早、仍使用旧更新源的版本需要先手动安装一次。
