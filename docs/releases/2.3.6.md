本次将外观更新、日常聊天和缓存请求诊断合并到同一版本。

- **全局材质**：保留毛玻璃、磨砂、水玻璃，通用卡片、列表、菜单和弹层跟随主题；修正输入栏偏色，更新手绘思考图标。
- **柔和暗色**：在“设置 → 颜色模式”选择灰调暗色。仅此模式对壁纸压暗，浅色模式保持图片原色。
- **设置共用背景**：在“显示设置 → 插图素材”选择一次背景，设置主页及配置子页面一起使用，已有图片可沿用。
- **日常聊天**：每个气泡旁显示头像，思考和工具过程默认隐藏，长按可查看记录及执行原有操作；工具确认仍正常出现，原始消息和执行过程不被删除。
- **显示修正**：修正抽屉切换时的材质图层、壁纸泛白和底部操作面板盖住聊天的问题；消息菜单可以滚动，较大字体下仍可访问底部操作。移除启动时强制显示的协议页，关于页面仍可查看协议。
- **缓存请求诊断**：正式版和 Debug 均可在“显示设置 → 消息显示”手动开启，默认关闭。从“设置 → 请求日志”查看系统提示、工具定义和历史消息最早变化的位置。比较支持 OpenAI 兼容 Chat Completions 的最终请求；只保存本机差异摘要，不保存聊天正文，不增加模型调用。首条请求建立基线，从下一次请求开始比较。此功能用于定位缓存问题，**不代表服务端命中率已经修复**。

本版不包含聊天引用功能。正式版为 **2.3.6**，Debug 为 **2.3.6-debug.1**，版本代码均为 **171**。沿用原渠道包名与签名，可覆盖安装；两套应用的数据仍相互独立。构建通过完整自动检查后发布，实际机型及模型服务体验仍需测试。
