# 整体主题材质

在「设置 → 显示 → 主题外观 → 整体主题材质」统一选择原始、毛玻璃、磨砂或水玻璃。配色仍独立选择。

- 毛玻璃：默认透明度 80%，柔雾轻透；滑杆数值越大越通透。
- 磨砂：柔润哑光，减淡底色、低反光与细微颗粒。
- 水玻璃：较低模糊、清透底色、圆润亮边和高光。没有光学折射模拟。

气泡、输入栏、侧边栏、会话条目和设置分组共用一个材质实现。标题栏及确认、风险确认、压缩、录音等常用弹窗接入同一规则。侧边栏和弹窗使用更厚的底色；其他原生菜单、弹窗和底部面板通过主题容器颜色保持可读，独立窗口不跨窗口采样模糊。

用户背景图、气泡图片、气泡显示开关与颜色设置继续保留。三种整体材质的输入栏跟随主题配色；旧的独立输入栏颜色保留给「原始」模式，避免旧颜色突然染满新材质。输入文本区不再叠加另一层不透明底色。默认背景使用纯底色，不再额外绘制装饰圆或渐变干扰用户壁纸与导航恢复。

新增 `displaySetting.themeMaterial`；缺失时采用毛玻璃默认值。旧的分项材质字段保留用于旧备份兼容，不再控制新界面。选择「原始」可以关闭统一材质。

复用 Haze 1.7.2，未添加依赖、后台任务或动画计时器。实时模糊只采样共享壁纸层，不采样包含自身效果的聊天列表；截图时关闭 Haze，使用静态绘制。设备不支持实时模糊时，Haze 使用更厚的静态底色降级。

验证：配置序列化、旧枚举名称、异常透明度、三种光学参数、深浅模式与弹窗可读性由 JVM 测试覆盖。完整 Android 编译、单元测试和 Lint 由 PR 检查执行；实际机型的显示效果及长列表滚动仍需安装包验收。
