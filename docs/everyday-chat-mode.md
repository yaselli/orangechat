# 日常聊天模式

入口：设置 → 显示设置 → 消息显示 → 日常聊天。默认关闭，旧备份保持完整模式。

- 用户在右，助手在左。按现有换行规则拆分显示，每个气泡各自带头像。代码块、表格继续共用现有保护规则。
- 左侧气泡左下角为 4dp，其余为 20dp；右侧镜像。共用整体主题材质、气泡颜色和自定义气泡图片。
- 思考、执行中的工具及完成的工具记录默认隐藏。原始消息、数据库、请求上下文和工具执行逻辑保持完整。
- 待用户确认或回答的工具保留原有交互入口。长按正文或附件打开消息操作，可查看完整思考和工具记录。
- 每轮的复制、重新生成、朗读、翻译等操作移入长按菜单；多分支选择仍可直接使用。
- 旧头像、模型名、气泡开关不被覆盖。切回完整模式恢复原设置。头像复用现有展示组件，重复气泡不注册头像编辑器和事件订阅。

验证包括分段规则、旧设置兼容、模式持久化、过程记录只读过滤与待确认工具可达性；Android 测试覆盖材质切换、双侧逐气泡头像、长按操作与镜像圆角。PR 检查通过后，同一源码提交自动生成 Debug 测试包，不公开发布。
